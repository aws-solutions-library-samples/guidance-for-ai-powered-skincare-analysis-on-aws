Turn skin photos into a routine built from your own catalog.

A user uploads one to three skin photos. Agents on Amazon Bedrock AgentCore analyze the skin, plan the routine and choose ingredients. A search over your own catalog then picks the matching products, and the routine streams back as each step completes.

What you get

Personal routines at scale

Agents analyze the skin, plan the steps and choose ingredients in parallel. Results stream to the browser as each agent finishes, so customers get consultation-style advice without a one-to-one session.

Products you actually carry

Products come from a search over your catalog, not from the model. Amazon OpenSearch Service ranks exact ingredient matches, and each pick is rechecked against the catalog records in Amazon DynamoDB.

Photos that are never stored

Amazon Bedrock Guardrails and output validation screen every model call. AWS WAF, Amazon Cognito sign-in, per-user limits and a private network for the agents reduce abuse and unauthorized access.

How it works

  1. Sign in and upload

    Amazon CloudFront serves the React app from a private Amazon S3 bucket behind AWS WAF. The user submits up to three photos of 1 MiB each.

  2. Authenticate

    Amazon Cognito signs the user in. Amazon API Gateway validates the ID token, and a second AWS WAF web ACL only admits traffic coming through CloudFront.

  3. Control access to the agents

    A streaming AWS Lambda proxy enforces per-user limits in Amazon DynamoDB and invokes Amazon Bedrock AgentCore Runtime. Photos are not stored.

  4. Analyze and plan

    In a private VPC, a skin-analysis agent uses an Amazon Bedrock multimodal model to build a skin profile. A planning agent chooses two to eight routine steps.

  5. Select products

    An ingredient agent picks ingredients for each step in parallel. Amazon OpenSearch Service ranks exact matches within your constraints, and each pick is rechecked in DynamoDB.

  6. Explain and assemble

    Agents explain the chosen products, screened by Amazon Bedrock Guardrails. The routine streams back to the browser as server-sent events.

  7. Keep the catalog current

    Product updates go to DynamoDB. A DynamoDB stream and Amazon EventBridge schedules drive Lambda workers that keep the search index in sync.

  8. Build and monitor

    AWS CodeBuild builds the agent image and pushes it to Amazon ECR. Amazon CloudWatch collects API, WAF, build and runtime logs.
